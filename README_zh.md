# APS 方法框架包

本包只包含论文正文中 APS 方法的核心实现，不附带任何具体应用场景、人口数据、实验预设、实验结果、基线或批量实验脚本。

## 包含什么

- 核心分组、尾部智能体选择与原型选择。
- 随人口规模变化的查询预算及残差驱动的组间分配。
- 根据邻近原型回答进行加权传播。
- 硬递归状态、软响应分布与审计校正报告的分离。
- 影子审计抽样、抽样概率、残差校正和风险诊断。
- 外部社会图的邻域摘要、三类查询计数及返回记录。
- 不绑定供应商的 LLM 接口和函数适配器。

场景事件、决策选项、初始状态、智能体特征、社会图及 LLM 调用均由使用者提供。包内没有默认中立状态、图生成规则或固定模型。整数决策使用从 0 开始的下标，也可直接返回选项的完整字符串。

## 安装与使用

```bash
python -m pip install .
python -m unittest discover -s tests -v
```

主入口是 `APSRunner.run`。参数和接口说明见 [README.md](README.md)，方法对应关系见 [docs/METHOD.md](docs/METHOD.md)，全部可调参数见 [docs/PARAMETERS.md](docs/PARAMETERS.md)。

`tests/` 中的小型数据仅用于检查代码逻辑，不是论文实验设置。结果对象在内存中返回，包本身不会写入运行日志、缓存、检查点或结果文件。

LLM 接口可以在 `OracleResponse.metadata` 中返回重试或响应修复信息，框架按智能体和查询类别保存到内存中的轮次记录。没有提供的信息不会补造。

## 本包的定位

这是从已有 APS 核心代码整理、修复得到的方法参考实现，不是产生论文全部实验结果的原始运行快照。它覆盖正文的方法流程，不包含千万级运行的专用工程流水线或附录动态记忆扩展。

已修复候选池限制导致原型重复、预算截断后未重新分配的问题，并增加输入、分组和审计覆盖检查。已知预算不足时会在本轮查询前报错，不会自动追加预算。

0.2.0 进一步对齐诊断量：局部分歧斜率按原型响应差异除以特征距离计算；单组审计样本不足两个时，残差方差标为 `None`，不再用残差平方替代。无法估计的项不参与本轮风险分数，其余可用诊断量继续参与。这些具体计算、边界处理及归一化规则均在方法说明中列出，不宣称它们就是产生论文原始实验结果的全部实现细节。
